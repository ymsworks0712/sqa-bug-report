# XYZ Bank Website Testing

This repository contains a manual testing bug report project conducted on the XYZ Bank website as part of my Software Quality Assurance (SQA) learning journey.

## Project Overview

The purpose of this project was to perform manual testing on the website, identify functional and UI-related issues, and document the discovered bugs in a professional bug reporting format.

## Testing Activities Performed

- Functional Testing
- UI Testing
- Navigation Testing
- Form Validation Testing
- Bug Identification
- Bug Documentation

## Files Included

- Bug_Report_XYZ_Bank_Customer_Login_Website.pdf
- Bug_Report_XYZ_Bank_Manager_Login_Website.pdf

## Tools & Skills Demonstrated

- Software Quality Assurance (SQA)
- Manual Testing
- Bug Reporting
- Documentation
- Test Observation
- QA Analysis

## Bug Report Contents

The report includes:

- ID
- Summary
- Environment
- URL
- Steps to Reproduce
- Screenshots
- Actual Result
- Screenshots
- Expected Result
- Type
- Priority
- Status

This project was created for educational and practice purposes during my SQA learning process by testing a publicly accessible website.
