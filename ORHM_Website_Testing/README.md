# ORHM Website Testing

This repository contains a manual testing bug report project conducted on the ORHM website as part of my Software Quality Assurance (SQA) learning and practice activities.

## Project Overview

The objective of this project was to identify and document functional issues in the ORHM website through manual testing techniques.

The testing process included verifying the password update functionality and analyzing the system behavior after changing user credentials.

## Bug Summary

### Bug ID
ORHRM-001

### Module
Change Password

### Issue
After successfully updating the password, the user cannot log in using the updated password. However, login is still possible using the old password.
